Assist & Auto-Targeting

Kill slow target swapping. One key sets the kill target on every DPS box off your Warrior main assist, fires attack, and sends pets in — sub-second, no clicking between windows.

⊕ The Assist Chain

You press ~ (tilde) on the Warrior window
↓ ISBoxer broadcasts to all DPS boxes
Each DPS box runs /assist Warmain
↓
Auto /attack on + /pet attack
↓
Bard/casters fire their nuke/DoT opener off new target
Warrior stays MA & MT. Because your driver is the tank, the tank's target = the kill target. No separate "assist character" to babysit.

◎ Auto-Target & Xtarget Setup

Make every box agree on the target without you looking at them.

  1. Warrior uses an Xtarget set to Auto Hater / Nearest NPC so it auto-acquires what's beating on the group.
  2. DPS boxes assist the Warrior by name — never by /target, which is order-dependent and breaks.
  3. Off-tank swaps: a second mapped key sends /assist off the Monk for split pulls / adds.
  4. Re-assist on add death: the same ~ re-fires; pets re-acquire automatically.

One key, two layers — fires on this box and broadcasts to healers.

Spell Gems & Hotbar Layout

Optimized gem order and hotbar mapping per caster so socials always hit the right slot. Consistent slotting across boxes is what makes broadcast macros reliable.

Rule: keep /cast 1..12 meaning the same spell type on every caster (e.g. slot 1 = primary nuke, slot 8 = emergency heal). Then one broadcast macro works across different classes.

Build & Setup Guide

End-to-end build order to get this ISBoxer command center running on both teams, plus the answers to your open spec questions.

✓ Build order

  1. Character Set — create one per team (Live8, TLP8). Add all 8 EQ instances, assign slots 1–8 in roster order.
  2. Window layout — main + swap-bar; set Repeater region for broadcast. Bind Pause = broadcast toggle.
  3. Action Target Groups — build AllDPS, Healers, Casters, Everyone (see Mapped Keys).
  4. Mapped keys — Assist (~), Burn (F1, stepped), Panic (F2), Pull (G), Follow (\), Buff, Broadcast-off.
  5. In-game socials — paste the per-class macros (EQ Social Macros tab) into each box's Socials, same hotbar slots.
  6. Spell gems & bars — slot per the Gems tab so /cast N is consistent across casters.
  7. Audio triggers — add named/proc/buff-fade triggers in EQ; map ISBoxer Alerts to pop the right box.
  8. Inventory — standardize bags across all boxes; set master looter on Warrior.
  9. Dry run — test assist → burn → panic → pull on green mobs before raiding your time on a named.

◐ Recommendations for your open questions

Accent colorCyan on dark

Cyan reads cleanest on a dark, information-dense layout: high contrast for status text without the eye-fatigue of pure white, and it never collides with EQ's own red(HP)/blue(mana)/yellow(caution) bars. Reserve amber for cooldowns and red strictly for panic.

Resolution (suggested)2560×1440
Monitor setupSingle ultrawide or dual

For 8-box at-a-glance: single 1440p main + swap-bar works; ultrawide is ideal (main view + always-visible healer column). Dual lets you park the swap-bar on monitor 2. Medium UI scale confirmed — keeps healer HP readable without eating the main view.
